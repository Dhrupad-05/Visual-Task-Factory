Visual Task Factory

Application story

Chart-reading errors in finance, healthcare, and operations dashboards can change decisions. This pipeline creates controlled charts whose answers come from the scene specification, then measures which visual traps cause model failures.

Validity evidence

Validator unit tests and golden fixtures are included in the repository. Dataset-level re-extraction, human agreement, and text-only baseline numbers must be supplied from the corresponding run logs before making claims.

Results and differentiators

Analysis code supports Wilson intervals, degradation summaries, misconception labels, minimal-pair flip rates, and severity sensitivity. This report does not invent model results when no evaluation artifact was supplied.

Limitations

  • Synthetic charts are not a substitute for real dashboard images.
  • The current renderer is primarily single-panel bar, line, and scatter.
  • Real-provider evaluation and human audits require operator credentials and review.
